\begin{tcolorbox}[title = \textcolor{black}{\textcolor{white}{Problema 1}}]
\textit{
La mediana de una variable aleatoria absolutamente continua con funci\'on de distribuci\'on $F$  es un valor $m$  tal que 
\[
F(m)=\frac{1}{2}
\]
Esto es, para una variable aleatoria es igual de probable que sea m\'as grande o m\'as pequeña que su mediana. Encuentra la mediana de la v.a. $X$ cuando $X\sim\mbox{Exp}(\lambda)$.
}
\end{tcolorbox}

\begin{tcolorbox}[title = \textcolor{black}{\textcolor{white}{Problema 2}}]

Use la desigualdad de Chebyshev para demostrar  que $\var(X)=0$ si, y s\'olo si, $X$ es constante. }
\end{tcolorbox}

}
\end{tcolorbox}

\begin{tcolorbox}[title = \textcolor{black}{\textcolor{white}{Problema 4}}]
\textit{Se desea encontrar a 20 personas que re\'unan ciertas caracter\'isticas para aplicarles un cuestionario. Si u\'nicamente el 1\% de la poblaci\'on cumple las caracter\'isticas requeridas y suponiendo que se consulta al azar a las personas para determinar si son adecuadas para contestar el cuestionario, determine el nu\'mero promedio de personas que se necesita consultar para encontrar a las 20 personas solicitadas.
}
\end{tcolorbox}


\begin{tcolorbox}[title = \textcolor{black}{\textcolor{white}{Problema 5}}]
\textit{En un estanque se tiene una cantidad desconocida M de peces. Primero, se atrapan 100 peces, se marcan y se regresan al estanque. Otro d\'ia, se toman muestras aleatorias sin reemplazo de tamaño 50 cada una y se observa que en promedio salen 10 peces marcados. Estima M.
}
\end{tcolorbox}

\begin{tcolorbox}[title = \textcolor{black}{\textcolor{white}{Problema 6}}]
\textit{
 Demuestra que si X y Y variables aleatorias independientes con distribuci\'on
  normal con par\'ametros $\mu_1, \mu_2, \sigma_1^2 \;y\;\sigma_2^2 $,
  entonces X+Y tamb\'ien es normal. Indica los nuevos par\'ametros  (usando la f.g.m.).
}
\end{tcolorbox}

\begin{tcolorbox}[title = \textcolor{black}{\textcolor{white}{Problema 5}}]
\textit{Sea Z una variable aleatoria normal est\'andar, y $X=\sigma Z+\mu$. 
\begin{enumerate}
\item Encuentra $\mathbb{E}[X]$ y $Var(X).$
\item Use la desigualdad de Chebyshev para estimar el valor m\'inimo de k de tal modo que la probabilidad de que X tome un valor entre $\mu-k\sigma$ y $\mu+k\sigma$ sea al menos 0.95.
\item Use la tabla de la distribuci\'on normal para encontrar el valor
  exacto de k que cumpla la condici\'on del inciso anterior.   
\end{enumerate}
}
\end{tcolorbox}

extra\'ida es roja y tenemos que pagar $20$ en el caso de que sea negra. ?`Qu\'e podemos esperar si jugamos muchas veces? 
}
\end{tcolorbox}
