# 📘 Tareas y Problemas – Facultad de Ciencias UNAM

Este repositorio contiene una amplia colección de tareas, problemas resueltos, apuntes y ejercicios relacionados con diversas materias impartidas en la Facultad de Ciencias de la UNAM, así como material adicional para preparación en olimpiadas y cursos externos.

## 🎯 Objetivo

Reunir y compartir material académico útil para estudiantes de la Facultad de Ciencias, aspirantes a olimpiadas, y entusiastas de las matemáticas, física y computación. El contenido está organizado por temas y cursos, con soluciones detalladas y archivos en LaTeX y PDF.

## 📁 Índice de Carpetas

| Carpeta                         | Descripción                                                                  |
|---------------------------------|------------------------------------------------------------------------------|
| `CIMAT`                         | Ejercicios del taller de Cálculo y la OMUM                                   |
| `ESFM`                          | Material de la Escuela Superior de Física y Matemáticas (IPN)                |
| `UNAM`                          | Material de la carrera de Matemáticas en la Facultad de Ciencias (UNAM)      |
| `Programacion_competitiva`      | Material acaerca de programacion competitiva (CSES,CODEFORECES,ICPC,ETC)     |
| `Olimpiadas de Física`          | Examenes selctivos y problemas variados                                      |
| `README.md`                     | Este archivo de descripción del repositorio                                  |
## 📦 Formato de los archivos

- Archivos `.tex` para edición en LaTeX
- Archivos `.pdf` listos para consulta
- Archivos `.c` con las resoluciones de problemas
- Algunos documentos incluyen imágenes, diagramas y explicaciones paso a paso

## 🛠️ Requisitos

Para compilar los archivos `.tex` necesitas tener instalado:

- [LaTeX](https://www.latex-project.org/get/)
- Paquetes comunes como `amsmath`, `geometry`, `graphicx`, `babel`, entre otros

## 🤝 Contribuciones

Este repositorio está abierto a contribuciones. Si deseas agregar tus propias tareas, soluciones o apuntes:

1. Haz un fork del repositorio
2. Agrega tu contenido siguiendo la estructura existente
3. Envía un pull request con una breve descripción

Por favor, mantén una organización clara y cita tus fuentes si usas material externo.

## 📌 Nota

Este repositorio es un recurso de apoyo académico. Úsalo como guía para tu aprendizaje, pero evita copiar directamente en tus tareas. El objetivo es fomentar el estudio, la curiosidad y el desarrollo de habilidades matemáticas y científicas.
